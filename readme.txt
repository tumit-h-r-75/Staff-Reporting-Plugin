A comprehensive staff reporting and salary management plugin.

== Description ==

This plugin allows staff members to submit daily reports and managers to review them, with salary calculation features.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/bassmah-staff-reports` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Configure the plugin settings
